# OtakuRate

Personal anime rating application.

## Goals

- Rate anime using a multi-criteria personal scoring system.
- Store anime and ratings locally in SQLite.
- Import and export rating data.
- Add Shikimori integration later.
- Keep the rating core independent from external services.

## Stack

- Python 3.14+
- PySide6
- SQLite

## Development

The project is currently in the initial development stage.
