# OtakuRate — контекст проекта

## Направление
Проект перезапущен как расширение для Яндекс Браузера. Старая версия сайта сохранена в ветке main и не затрагивается этой веткой.

## Назначение
На страницах Shikimori распознавать текущий тайтл и выставлять собственные оценки по критериям 0–10. В перспективе — каталог, профиль, статистика, настраиваемые веса и серверная синхронизация.

## Текущая реализация в extension-rebuild
- Manifest V3.
- Всплывающее окно оценивания.
- Content script для страниц /animes/{id} и /mangas/{id} на shikimori.one, shikimori.me и shikimori.org.
- Критерии аниме и манги/манхвы.
- Локальное сохранение оценок и комментариев через chrome.storage.local.
- Страница настроек-заготовка.
- Roadmap отражает незавершённые функции.

## Ограничения
- Реальное извлечение года, количества серий/глав и изображения нужно проверить на DOM текущего Shikimori.
- Нет каталога со всеми сохранёнными тайтлами, статистики, редактора весов, регистрации и синхронизации.
- Пока нет автоматических тестов и проверки в браузере.

## Технологии
Vanilla JavaScript, HTML, CSS, Manifest V3; внешние зависимости не используются. Новые зависимости, если они понадобятся, должны быть отражены в файлах проекта и документации.

## Следующий шаг
Установить расширение локально в Яндекс Браузере, проверить обнаружение тайтла и сохранение оценки, затем исправить извлечение метаданных по фактической разметке Shikimori.
